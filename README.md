# 🏦 Yashpython Bank System

A simple banking program offering both a CLI (command-line interface) menu and a Tkinter-based graphical user interface (GUI)[cite: 3].

## Features
- **Deposit**: Add funds to the account balance.
- **Withdraw**: Deduct funds with insufficient balance checks.
- **Balance Check**: Display current balance.
- **Dual Interface**: Includes CLI and Tkinter GUI models.

## How to Run
```bash
python banking_system.py
