# 🏦 Yashpython Bank System

A simple banking program offering both a CLI (command-line interface) menu and a Tkinter-based graphical user interface (GUI)[cite: 3].

## Features
- **Deposit**: Add funds to the account balance[cite: 3].
- **Withdraw**: Deduct funds with insufficient balance checks[cite: 3].
- **Balance Check**: Display current balance[cite: 3].
- **Dual Interface**: Includes CLI and Tkinter GUI models[cite: 3].

## How to Run
```bash
python banking_system.py
